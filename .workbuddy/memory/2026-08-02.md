## TTS 二次修复：请求格式（00:06）

用户重启后 TTS 仍失败，新错误："The parameter `Action` is not recognized"。

**根因**：腾讯云 API 3.0 规范要求 Action/Version/Region 作为公共参数放请求头（X-TC-Action 等），我们的代码把它们也放进了 JSON body。新版 TTS（2019-08-23）严格校验 body 参数，把 body 里的 "Action" 当未知业务参数拒绝。ASR 同理（之前从未真正调通过——STT 注解缺失+格式问题）。

**修复**（VoiceServiceImpl）：
- synthesizeSpeech / recognizeSpeech：从 JSON body 移除 Action/Version/Region（保留在 doPost 的 X-TC-* 请求头中）
- recognizeSpeech 补 DataLen（音频字节数，ASR 必需参数）

**状态**：代码已提交。用户后端用 java -jar 启动锁住 target jar，无法重新打包；已告知用户：停后端 → ./mvnw.cmd package -DskipTests → 重启。
