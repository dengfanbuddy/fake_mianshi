## Bug 修复：ApiResponse code 不一致（23:30）

用户反馈设置页保存 DeepSeek 配置失败（红色 success 提示、刷新后列表为空）。

**根因**：后端 ApiResponse.success() 返回 code=0（成功），前端所有页面（30+ 处）判断 `res.code === 200`。配置实际已保存成功（DB 验证：id=2 deepseek-v4-flash is_active=1），前端误判失败。

**修复**：frontend/src/api/request.js 拦截器把 `code===0` 归一化为 `200`，一处修复全部页面。Vite HMR 即时生效，无需重启后端。

**遗留提醒**：用户配置的 apiUrl 是 https://api.deepseek.com/anthropic（Anthropic 兼容端点），但 LlmServiceImpl 发 OpenAI 格式请求，组合不兼容。需提醒用户改用 OpenAI 兼容端点 /v1/chat/completions。
