### 关键决策摘要
- 项目定位：个人面试训练工具，同时作为 Java 简历项目
- 技术栈：Vue3 + Spring Boot + SQLite + DeepSeek API + 腾讯云语音
- 笔试：单选/多选/填空/简答，限时，不手写代码
- 模拟面试：动态生成，不限时，语音对话，录音保存
- 面试官风格：预设+自定义，支持中途换人，影响 TTS
- 自适应出题：弱点标签 + LLM 混合模式
- 语音交互：MVP 录音后发送，后续迭代实时流式
