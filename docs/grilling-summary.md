# Grill With Docs — 总结

**日期：** 2026-08-01
**状态：** Grilling 完成

## 项目概述

AI 驱动的 Java 面试模拟系统，用户（Java 开发者，离职求职中）用于持续面试训练和查漏补缺。系统根据简历/职位需求 AI 生成面试题，支持笔试和语音模拟面试两个阶段，面试后生成多维度分析报告，并基于历史表现自适应出题。

## 已决策清单

### 领域概念（详见 CONTEXT.md）

| 概念 | 决策 |
|------|------|
| 面试会话 | 笔试→模拟面试，两阶段可独立发起，可跳过任一 |
| 笔试 | 单选/多选/填空/简答，限时（默认60分钟，可配置），不手写代码 |
| 模拟面试 | 动态生成问题，不限时，语音对话，可引用笔试结果追问 |
| 简历分析 | PDF 格式，AI 解析提取经验/技术栈/项目等 |
| 职位需求 | 简历驱动（AI 建议岗位→确认）或手动描述 |
| 面试官风格 | 预设+自定义，手动/随机/智能推荐，支持中途换人，影响 TTS |
| 语音交互 | MVP 录音后发送模式，腾讯云 ASR+TTS，录音保存 |
| 面试分析 | 单题/单次/历史三层分析，结束后一次性生成 |
| 面试项目 | 按目标岗位分组管理，绑定简历+职位+历史 |
| 自适应出题 | 混合模式：弱点标签 + LLM 出题 |
| AI 模型 | DeepSeek API（可配置切换） |

### 架构决策（详见 ADR）

| ADR | 决策 | 核心理由 |
|-----|------|----------|
| 0001 | Spring Boot + Vue3 + SQLite | Java 简历加分，AI 调用是 REST API 与语言无关，SQLite 免安装 |
| 0002 | 自适应出题混合模式 | 平衡精准度与维护成本，无需完整知识图谱 |
| 0003 | 录音后发送 + 腾讯云语音 | MVP 优先验证核心体验，实时流式后续迭代 |

## 技术栈

| 层 | 选型 |
|----|------|
| 前端 | Vue3 + Element Plus |
| 后端 | Spring Boot |
| 数据库 | SQLite |
| LLM | DeepSeek API（可配置） |
| STT | 腾讯云 ASR |
| TTS | 腾讯云 TTS |
| 简历解析 | PDF → 后端文本提取 → LLM 结构化分析 |

## 仍开放的问题

以下为实现阶段需进一步细化但不影响架构的细节：

1. **预设面试官风格具体有哪些** — 已确定机制（预设+自定义+推荐），但 4-5 种预设风格的具体定义待设计
2. **弱点标签数据结构** — 知识点 + 掌握程度 + 出现次数 + 最后面试时间，具体字段待细化
3. **笔试题量** — 每次笔试出多少题（按题型分配），可做成可配置参数
4. **部署方式** — 本地运行 or Docker，个人项目本地即可
5. **LLM Prompt 工程** — 各环节（简历分析、出题、对话、分析）的具体 prompt 设计，属实现细节
