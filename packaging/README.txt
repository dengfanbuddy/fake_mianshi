模拟面试系统 - 离线一键启动包
================================

【这是什么】
这是一个“模拟面试系统”，包含：
  - 后端：Spring Boot 服务（已打成 app.jar）
  - 前端：Vue 页面（已打包进 app.jar，随服务一起提供）
  - 运行环境：已内置 Java 17 运行环境（jre 文件夹）

本包不需要安装 Java、不需要安装数据库、不需要联网安装任何依赖，
适合直接拷贝给没有 Java 环境的用户使用。

【如何启动】
1. 双击文件夹里的  start.cmd
2. 系统会自动启动后台服务，并等待就绪后自动打开浏览器页面。
3. 启动成功后，浏览器中显示的地址一般为：
     http://localhost:8080/
4. 停止服务：关闭弹出的那个黑色命令行窗口即可（关闭窗口即停止服务）。

如果浏览器没有自动弹出，请手动访问上面的地址。

【首次启动会做什么】
- 自动在程序目录下创建 data/ 数据库文件（SQLite）和 uploads/ 上传目录。
- 自动初始化数据库表，并预置一些示例数据（AI 模型配置、面试官风格等）。
因此首次启动可能需要几秒到十几秒，请耐心等待提示“服务已启动”。

【文件夹说明】
  start.cmd  一键启动脚本（双击运行）
  app.jar    后端 + 前端打包后的程序文件
  jre\       Java 17 运行环境（自带的，无需另行安装）
  data\      运行时自动生成的数据库（首次启动后产生）
  uploads\   运行时自动生成的简历/录音存储目录（首次启动后产生）

【可选：修改端口】
如默认的 8080 端口被占用，或想换端口：
1. 用记事本打开 start.cmd
2. 把  set "PORT=8080"  改成其他端口，例如  set "PORT=9090"
3. 保存后重新双击 start.cmd

【可选：配置语音（腾讯云）】
“语音面试”功能需要配置腾讯云语音识别(ASR)/合成(TTS)密钥。
两种方式任选其一：
  (1) 在程序的“设置”页面里直接填写腾讯云 SecretId、SecretKey、AppId 并保存。
  (2) 或用系统环境变量：
         TENCENT_SECRET_ID
         TENCENT_SECRET_KEY
         TENCENT_APP_ID
未配置时，文字面试不受影响，只是语音相关功能不可用。

【常见问题】
Q: 双击后黑窗口一闪而过？
A: 说明本文件夹不完整，缺少 jre 或 app.jar。请确保整个文件夹一起拷贝，不要只拷 start.cmd。
Q: 提示“端口被占用”或无法打开页面？
A: 关闭所有浏览器/命令行中占用 8080 的程序，或按上面方法换一个端口。
Q: 浏览器打开了但空白？
A: 请用 start.cmd 启动方式（保证同时打开后端），并等待“服务已启动”提示后再用。
Q: 关闭命令行窗口后服务就停了吗？
A: 是的，关闭那个窗口即停止服务，无需专门卸载。
